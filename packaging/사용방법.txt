DART 쉬운 가이드 사용 방법

Python이나 다른 프로그램을 설치하지 않아도 Windows 10/11(64비트)에서 실행됩니다.


1. 실행하기

  1) 받은 ZIP 파일을 마우스 오른쪽 버튼으로 눌러 [압축 풀기]를 선택합니다.
     ZIP 안에서 바로 실행하면 동작하지 않습니다.
  2) 압축을 푼 폴더에서 DartGuide.exe를 더블클릭합니다.
     폴더 안의 다른 파일을 지우거나 옮기면 실행되지 않습니다.
  3) 바탕화면에서 쓰려면 DartGuide.exe의 바로 가기를 만들어 옮겨 주세요.

  "Windows의 PC 보호" 창이 뜨는 경우
  서명되지 않은 프로그램이라 나타날 수 있습니다. 믿을 수 있는 사람에게 받은 파일이면
  [추가 정보]를 누른 뒤 [실행]을 누르세요.
  회사 PC에서 차단되면 보안 담당자에게 실행 허용을 문의해 주세요.


2. 인증키 준비

  이 프로그램을 쓰려면 본인의 OpenDART 인증키(40자리)가 필요합니다. 발급은 무료입니다.

  1) https://opendart.fss.or.kr 에 접속합니다.
  2) [인증키 신청/관리]에서 인증키를 신청합니다.
  3) 이메일 인증을 마친 뒤 40자리 인증키를 확인합니다.
  4) 프로그램에서 처음 조회할 때 나타나는 입력창에 붙여 넣습니다.

  인증키는 다른 사람과 공유하지 마세요.
  입력한 키는 Windows 암호화 기능으로 저장되어 이 PC의 내 Windows 계정에서만 풀 수 있습니다.
  회사망처럼 보안 장비가 통신을 검사하는 환경에서는 조회할 때 그 장비에 키가 보일 수 있습니다.


3. 사용하기

  [예제로 시작]
  1) 왼쪽 메뉴에서 [예제로 시작]을 누르고 궁금한 질문을 고릅니다.
  2) 회사를 선택합니다. 처음 한 번은 회사 목록을 내려받습니다.
     후보 목록에는 대표이사가 함께 표시되어 이름이 같은 회사를 구별할 수 있습니다.
  3) [결과 보기]를 누릅니다. 기본값은 가장 최근 공시까지 반영합니다.
  4) [PDF로 저장]을 누르면 정리된 내용을 파일로 받을 수 있습니다.

  [업체 분석]
  회사 이름을 넣으면 업체 정보, 3개년 재무, 수출·수입, 파생거래를 한 화면에 정리합니다.
  파생거래는 상품 종류, 통화별 액면, 매도·매입, 약정환율, 만기, 거래상대방까지 보여 줍니다.
  공시에 액면이 없으면 "미공시"로, 단위가 불분명하거나 기말 전에 만기가 끝난 계약은
  "(확인)"이나 "(만기 경과)"로 표시하고 합계에서 뺍니다. 원문과 대조해 주세요.
  [최근 3개월 뉴스 포함]을 켜 두면 기준일(기본값 오늘)부터 거슬러 3개월 동안의 뉴스를
  AI가 웹에서 찾아 5번 항목에 넣습니다. 공시 분석이 먼저 나오고 뉴스는 2~4분 뒤에 채워집니다.
  - 월별·주제별 검색과 신용·자금(회사채, 신용등급, 차입, CB, M&A, 소송) 집중 검색을 함께 돌립니다.
  - 기사마다 여신·외환 관점 중요도(상·중·하)와 이유를 붙이고, '상' 기사는 위에 따로 모읍니다.
  - 같은 기간 DART 공시와 대조해 같은 사건의 공시가 있으면 [공시 대조] 칸에 연결합니다.
  AI 에이전트와 같은 연결(Claude Code 로그인, 없으면 Claude API 키)을 쓰며 그만큼 사용량이 듭니다.
  검색 결과로 확인되지 않은 기사나 기간 밖 기사는 앱이 뺍니다. 중요도는 AI 판단이니 원문을 확인해 주세요.

  [파생 전수조사]
  DART에 보고서를 낸 회사 전체를 대상으로 파생거래 기재 여부와 액면을 모읍니다.
  1) 사업연도와 조사 대상을 고르고 [1. 대상 확인]으로 건수와 예상 사용량을 봅니다.
  2) [2. 조회 시작]을 누릅니다. 인증키 하루 한도를 넘지 않게 속도를 조절하며,
     한도에 닿으면 다음 날 0시 5분 이후에 이어서 조회합니다.
  3) 수천 건이라 여러 날 걸릴 수 있습니다. 프로그램을 닫아도 다음에 이어서 진행합니다.
  4) [CSV로 저장]으로 요약, 표 내용, 계약 상세를 엑셀에서 열 수 있는 파일로 받습니다.
  전수조사 중에는 같은 인증키를 쓰는 다른 조회도 하루 한도를 함께 씁니다.

  [AI 에이전트]
  공시 내용을 대화로 묻고 답을 받습니다. 업체 분석의 [AI 종합 의견]도 같은 방식입니다.
  연결 방법은 두 가지이며, Claude Code 로그인이 있으면 항상 로그인을 먼저 씁니다.

  가. Claude Code 로그인 (본인 Claude 구독 사용량을 씀)
  1) VS Code에 Claude Code 확장을 설치하고 Claude 계정(Pro, Max 등)으로 로그인합니다.
     확장 없이 Claude Code만 설치해 로그인해도 됩니다.
  2) [AI 에이전트] 화면에서 연결 상태를 확인합니다. 로그인이 필요하면 [Claude 로그인]을 누릅니다.

  나. Claude API 키 (로그인이 없을 때만 씀, 쓴 만큼 요금 청구)
  1) https://platform.claude.com/settings/keys 에서 API 키(sk-ant-api…)를 발급합니다.
  2) [인증키·설정]의 [Claude API 키]에서 [키 입력 / 변경]으로 저장하고 [연결 테스트]를 누릅니다.
     키는 Windows 암호화 기능으로 저장되고 Claude Code에는 넘기지 않습니다.
  3) API 키로 대화하던 중 Claude Code에 로그인하면 다음 질문부터 로그인으로 바뀝니다.

  질문을 입력하고 [보내기]를 누릅니다.
  AI 답변도 공시를 정리한 참고 자료이므로 중요한 숫자는 공시 원문을 확인해 주세요.


4. 삭제하기

  1) 압축을 푼 폴더를 삭제합니다.
  2) 저장된 인증키(OpenDART, Claude API), 회사 목록, 파생 전수조사 결과까지 지우려면, 탐색기 주소창에
     %LOCALAPPDATA%\DartGuide 를 입력해 열린 폴더를 삭제합니다.


5. 꼭 알아 두세요

  이 프로그램은 금융감독원이 만든 공식 프로그램이 아니며, OpenDART 공개 API를 활용합니다.
  결과는 공시를 정리한 참고 자료로, 투자 권유나 투자 판단의 근거가 아닙니다.
  중요한 내용은 반드시 공시 원문을 확인해 주세요.
